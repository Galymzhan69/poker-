# POKER CLUB Telegram bot

## Что есть в этой стартовой версии
- Русский интерфейс.
- Регистрация игроков и SQLite-профили.
- 20 стартовых игровых очков.
- Список открытых столов, предпросмотр стола без показа закрытых карт.
- Создание столов на 2–6 игроков.
- Texas Hold'em: раздача двух закрытых карт, флоп/тёрн/ривер.
- Проверка комбинаций из 5 карт.
- Кнопки Check, Call, Raise, Fold.
- Админ-команды: /admin, /addpoints, /ban, /unban, /closeall.

## Важное ограничение
Очки и фишки предназначены только для бесплатной тренировки. Они не продаются,
не переводятся между игроками, не выводятся и не имеют денежной стоимости.
Фишки за столом сбрасываются вместе с раздачей; это не денежный баланс.

## Установка
1. Установите Python 3.10+.
2. Скопируйте `.env.example` в `.env`.
3. В `.env` укажите BOT_TOKEN и ADMIN_IDS (Telegram user ID админа).
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите: `python main.py`

## Команды администратора
- `/admin`
- `/addpoints USER_ID AMOUNT`
- `/ban USER_ID`
- `/unban USER_ID`
- `/closeall`

## Примечание
Это MVP-каркас для тестирования. Столы хранятся в памяти процесса и исчезнут
после перезапуска. Перед публичным запуском нужны дополнительные тесты и доработки
по восстановлению раздач, корректной обработке side pots/all-in и устойчивости.
